# Проект: Интернет-магазин (M4)

## Описание
Серверное веб-приложение интернет-магазина с использованием Java Servlets, JSP, JDBC и базы данных MySQL. 
Реализована архитектура MVC, аутентификация пользователей, корзина, оформление и история заказов.

## Технологический стек
- Java 11+
- Apache Tomcat (через Maven Tomcat Plugin)
- Maven (сборка и запуск)
- MySQL 8.0+ (База данных)
- Servlets & JSP (Backend & Frontend)
- JDBC (взаимодействие с БД)
- BCrypt (хеширование паролей)

## Инструкция по запуску

### 1. Требования
- JDK 11 или 17
- Apache Maven 3.6+
- Сервер MySQL (локальный или в Docker)

### 2. Настройка базы данных
1. Создайте пустую базу данных с именем `shop` (кодировка UTF-8).
2. Импортируйте файл `init.sql`:
   ```bash
   mysql -u root -p PASSWORD < init.sql
3. Для Docker:
    ```bash
    docker exec -i DBNAME mysql -uroot -proot PASSWORD < init.sql)
    ```
4. Запуск приложения
Откройте терминал в корне проекта и выполните:
	```bash
	mvn tomcat7:run
Приложение будет доступно по адресу: http://localhost:8080
5. Тестирование
При первом запуске создайте аккаунт через страницу регистрации.
Войдите в систему и проверьте сценарии: каталог → корзина → оформление заказа → история заказов.

### 3. Структура проекта
- src/main/java/com/shop/ — исходный код (Beans, DAO, Controllers, Utils)
- src/main/webapp/ — JSP-шаблоны, CSS, статика
- pom.xml — конфигурация Maven и зависимости
- init.sql — скрипт инициализации БД и тестовые данные
